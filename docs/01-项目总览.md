# 01 · 项目总览

> 版本 `0.2.2` / `versionCode 3` · 基于 2026-11-22 源码通读。

## 1. 定位

**AutoLedger（自动记账）** 是一个**单机** Android 记账应用：

- **不需要账号、不需要服务器**：账目、分类、预算、周期规则全部存本机 Room 数据库；只有用户主动配置后才产生两类网络请求（AI 识图发给用户自选的模型商；WebDAV 备份发给用户自填的网盘）。
- **核心卖点是"自动"**：从支付通知、短信、屏幕截图三条渠道把消费流水自动变成账单，减少手记。
- **双形态**：普通 App（装完即用）+ 可选 LSPosed 模块（`scope=system`，用于把被系统关掉的采集通道写回，当前为骨架级）。
- **免 Root 优先**：截屏记账在 Android 11+ 走系统 `AccessibilityService#takeScreenshot()`，无需 Root；Root/MediaProjection 是补充路径。

## 5. 构建与运行

仓库**自带 Gradle Wrapper**（`gradlew` / `gradlew.bat`，Gradle 9.4.1），无需全局安装 Gradle：

```bash
# 调试包（本地默认，允许明文 HTTP 便于连自建 WebDAV / AI 网关）
./gradlew :app:assembleDebug

# 发布包（开启 R8 混淆 + 资源压缩；无 keystore.properties 时回退 debug 签名）
./gradlew :app:assembleRelease

# UI 一致性门禁（CI 第一步就是它）
bash tools/check-ui-consistency.sh

# 可选：Kotlin 语法自检（CI 未调用）
python3 tools/check-kotlin-syntax.py
```

- **签名**：在仓库根放 `keystore.properties`（`storeFile` / `storePassword` / `keyAlias` / `keyPassword`）即启用真实 release 签名；否则 `release` 回退 `debug` 签名，保证本地能构建。
- **CI**：`.github/workflows/android.yml`，ubuntu-latest + temurin 21 + Gradle 9.4.1 + SDK android-37，先跑 `check-ui-consistency.sh`，再 `assembleDebug` / `assembleRelease`，产物 artifact 保留（debug 30 天 / release 90 天）；打 `v*` tag 时用 `softprops/action-gh-release` 发布。

## 6. 首次使用路径

1. 安装 APK → 打开，授予**通知权限**（Android 13+ 弹窗）。
2. 「设置 → 权限与后台」逐项体检并授权：**通知使用权**（通知监听，必需）、**无障碍**（截屏记账，可选）、**短信权限**（短信记账，可选）、**电池白名单**、**精确闹钟**、所需**通知渠道**。
3. 「设置 → AI 与高级功能」填 **Base URL / API Key / Model**（OpenAI 兼容），才会启用 AI 识图。
4. 可选：「设置 → 数据与备份」填 **WebDAV**（坚果云填应用密码），开启自动备份。
5. 用「记一笔」或截图/通知/短信任一渠道产生第一笔账；首页即按天分组展示。
