## 2. 什么算"反模式"（判据）

改造中确立的判据，供后续新增页面/代码复用：

1. **色值硬编码**：任何 `Color(0xFF…)` / `Color.White` 直接出现在业务代码里 → 颜色必须取自 `LedgerPalette`（唯一色值真源）。
2. **页面级主题**：页面里再包一层 `MiuixTheme(...)` / `MaterialTheme(...)` → 全 App 只允许 `LedgerApp` 里的 `AppTheme` 一个主题根。
3. **散落魔法数**：`fontSize = 14.sp` / `fontWeight = …` / `RoundedCornerShape(14.dp)` 直接写在组件里 → 走 `LedgerTextStyles` / `LedgerDimens` 三层 token。
4. **Toast 当反馈**：Composable 页面里用 `Toast.makeText` 提示 → 用全局 `LedgerSnackbar` / `LocalSnackbar`。
5. **玻璃当默认**：把 `GlassSurface` / 毛玻璃当内容卡默认材质 → 玻璃只保留在根容器背景层，内容层一律实心 `surface` + 1dp `borderSoft`。
6. **触摸目标不足**：可点元素 <44dp（目标 48dp）→ 加最小热区或外扩 padding。
7. **底部留白不足**：列表底部无安全余量，最后一项被底栏/手势条盖住 → 预留 ~82dp。

## 6. 可复用规则（后续任何 UI 改动都遵守）

1. **色值唯一真源 = `ui/theme/LedgerPalette.kt`**：任何新色先进 `LedgerColors` 的 light/dark 两组实例，再经 `LedgerPalette.of(isDark)` 取用；禁止 `Color(0x…)` / 命名色。
2. **字号唯一真源 = `ui/theme/LedgerTextStyles.kt`**：14 个 Miuix 文字槽统一覆盖；`headline1` 不覆盖（Miuix 列表行/偏好项标题内部读它）；大金额一律走 `amountDisplayStyle()`（34/42 Bold tnum End），**不要**用 `textStyles.headline1` 放大。
3. **尺寸唯一真源 = `ui/theme/LedgerDimens.kt`**：间距阶梯 `xs4/sm8/md12/lg16/xl24/xxl32`，圆角阶梯 `radiusSm8/radiusMd12/radiusLg16/radiusXl24/radiusDialog28`，胶囊 `radiusCapsule 50dp`。R6 只认这 7 个值。
4. **主题唯一根 = `ui/theme/AppTheme.kt`**：只在 `LedgerApp` 调用一次；页面内禁止再包 `MiuixTheme`/`MaterialTheme`。`AppTheme` 先写 `LedgerTheme.dark` 再建 `ThemeController`，保证"我们算的深色"与"Miuix 算的深色"同帧一致。
5. **细线豁免**：元素高度 ≤6dp 的装饰线/把手，圆角允许为高度一半（如 2dp/3dp）。
6. **功能值豁免**：图表绘制参数、emoji 视觉字号、对齐计算值（如 `HomeScreen` 66dp 顶栏计算高度）不计入魔法数考核。
7. **玻璃降级原则**：玻璃/毛玻璃只允许出现在根容器背景层；所有内容层（卡片、行、按钮）用实心 `surface` + 1dp `borderSoft`。
8. **反馈规范**：Composable 页面用 `LedgerSnackbar`/`LocalSnackbar`；仅 BroadcastReceiver / TileService / 透明 Activity 等无 Compose 宿主才允许 `Toast`。
