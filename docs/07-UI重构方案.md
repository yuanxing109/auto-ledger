# 07 · UI 重构方案（历史存档：M3 / Lottie / MPAndroidChart / Compose Icons / LXGW WenKai）

> **状态：已被 [`08` A 方案（Miuix 单源）](08-A方案-Miuix单源与图表迁移.md) 取代。**
> 本文保留作决策档案：记录当时评估过哪些库、为何最终**没选** M3 / MPAndroidChart，以及哪些想法（LXGW 文楷、Compose 图标）被 A 方案继承。
> 文中"M3 ColorScheme""MPChartCompose""P0–P3 迁移"等**均未落地**，不要按本文施工。当前真源见 [`06`](06-UI统一改造方案.md) / [`09`](09-设计系统.md)。

## 0. 结论摘要

- 曾规划引入 **Material 3 + GearUI/Lottie + MPAndroidChart(MPChartCompose) + Compose Icons + LXGW 文楷**，把三套自绘 Canvas 换成图表库、把自绘色源换 M3 `ColorScheme`。
- 评估后**整体放弃**：项目已选 **Miuix 单源**（[`08`](08-A方案-Miuix单源与图表迁移.md)），再叠一层 M3 会形成第二套色源/组件体系，正是要消灭的问题。
- 被继承的想法：**LXGW 文楷**（作为 `LedgerTextStyles` 各槽 `fontFamily` 的可选接入点，尚未落地子集化）、**Compose 图标**（`MiuixIcons` + `ui/AiScanIcon.kt`）。
- 被否决的想法：M3 `ColorScheme`（与 Miuix 冲突）、MPChartCompose（**至今报表仍是自绘 Canvas**，未引入任何图表库）、Lottie（高频工具页不需要重动效）。

---

## 1. 每个库的取舍（当时的评估，结论）

| 库 | 拟负责 | 结论 | 理由 |
| --- | --- | --- | --- |
| Material 3 | 配色 + 组件 | **否决** | 与 Miuix 单源冲突，会造第二主题 |
| GearUI | 拟物组件 | 否决 | 风格不符极简方向 |
| Lottie | 动效 | 否决 | 记账是高频效率工具，重动效拖慢操作 |
| MPAndroidChart / MPChartCompose | 报表图表 | **未采用** | 报表至今是自绘 Canvas（`ui/screen/ReportScreen.kt`）；引入需评估体积/Compose 互操作，暂缓 |
| Compose Icons / MiuixIcons | 图标 | **采用** | 统一图标来源 |
| LXGW 文楷 | 中文字体 | **保留为可选接入点** | 数字组永不换字体（楷体 0/6/8 在 34sp 难分辨），接入点是 `LedgerTextStyles` 各槽 `fontFamily` |

## 2. 当时的视觉与组件规范（现状以 [`06`/`09`](06-UI统一改造方案.md) 为准）

- 2.1 配色（原写「`LedgerTheme` → M3 `ColorScheme`」）→ **改为 `LedgerPalette` → Miuix 53 槽**（见 08 §1.3）。
- 2.2 字体（LXGW 文楷 + 数字等宽，需要 GB2312 子集化）→ 数字 `tnum` 已落地；文楷子集化**未落地**。
- 2.3 图标（`AppIcons`）→ 实际用 `MiuixIcons` 优先 + `ui/AiScanIcon.kt`。
- 2.4 图表（MPChartCompose）→ **未落地，仍自绘 Canvas**。
- 2.5 动效白名单（时长曲线）→ 收敛为：覆盖层 200ms fade、三页签 160/120ms、DockTab spring（`LedgerApp.kt`），并尊重系统动画缩放（`ValueAnimator.getDurationScale()` 为 0 则瞬时）。
- 2.6 组件清单 → 以 Miuix 组件白名单为准（08 §1.5）。

## 4. 现状约束（依然成立的部分）

- `minSdk 27`（Android 8.1）——部分新 API 需运行时判断（如 `AlarmManager.canScheduleExactAlarms`、`AccessibilityService.takeScreenshot` 需 Android 11+）。
- 报表/图表必须在 `DrawScope` 内取色 → 故保留 `LedgerTheme` 转发层（`LedgerPalette` 的只读投影），不能在 `Canvas` 里读 `CompositionLocal`。
- 金额强等宽：`fontFeatureSettings = "tnum"`。
