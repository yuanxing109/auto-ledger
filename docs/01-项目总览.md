# 01 · 项目总览

> 本文档基于工作区实际源码逐文件通读生成（2026-11-20），所有结论均可在对应文件定位。

## 1. 定位

AutoLedger（自动记账）是一个**单人自用的 Android 本地记账 App**：

- 语言/UI：Kotlin + Jetpack Compose，视觉层用 **Miuix 0.9.5-beta01**（小米澎湃风格），主题支持 **跟随系统 / 浅色 / 深色** 三态（`ui/LedgerTheme.kt` 语义色板 + `ui/LedgerApp.kt` 驱动 `ThemeController`）。
- 数据：**Room 2.8.5**（KSP 生成），单表 `Bill`，DAO 全 `Flow`，无网络后端。
- 自动采集：截屏 → 多模态模型识别 → 通知栏确认 → 入账；通知监听（支付宝/微信/银行/短信应用/外卖出行）**已落地**；短信广播（`SMS_RECEIVED`）也已落地；LSPosed 注入仍是骨架。
- 扩展形态：同时是一个 **LSPosed 模块**（`scope.list = system`），当前仅系统级日志占位。

一句话：**手动记账已经可用，截屏 + AI、通知监听、短信广播三条自动链路都通了；模块注入仍是骨架。**

## 3. 技术栈（实测版本）

### 3.1 构建

| 项 | 值 | 来源 |
| --- | --- | --- |
| AGP | `com.android.application` **9.2.0** | `build.gradle.kts:2` |
| Kotlin Compose 插件 | `org.jetbrains.kotlin.plugin.compose` **2.4.20** | `build.gradle.kts:3` |
| KSP | `com.google.devtools.ksp` **2.3.12** | `build.gradle.kts:4` |
| Gradle | 需 **9.4.1+**（AGP 9.2 要求）；**仓库未包含 Wrapper** | 工作区无 `gradlew`/`gradle/wrapper/` |
| compileSdk | **37**（minorApiLevel 2 → 37.2） | `app/build.gradle.kts` |

| versionCode / versionName | **1** / **0.1.0** | 同上 + `META-INF/xposed/module.prop` |
| Java | **17**（source/target 均 17） | `app/build.gradle.kts` |
| JVM 参数 | `-Xmx4096m -Dfile.encoding=UTF-8`，`org.gradle.parallel=true` | `gradle.properties` |

> 说明：`app/build.gradle.kts` 的 plugins 块只声明了 `com.android.application`、`org.jetbrains.kotlin.plugin.compose`、`com.google.devtools.ksp`，**没有显式 `kotlin-android`**；Kotlin 版本随 Compose 插件 2.4.20 与 AGP 9 的内建 Kotlin 支持走（此为对构建插件的解读，非官方文档结论）。

## 5. 构建与运行

```bash
# 本机需 Gradle 9.4.1+（仓库无 wrapper，需全局安装或用新版 Android Studio 触发）
cd "D:/个人项目/auto-ledger"
gradle :app:assembleDebug
# 或直接安装
gradle :app:installDebug
```

**环境要求**：JDK 17、Android SDK Platform 37（Build-Tools 侧需支持 API 37）、KSP 与 Room 版本必须匹配（2.3.12 / 2.8.5）。

已知构建风险：
1. 缺 Wrapper → CI 或新机器上无法 `./gradlew`，必须先 `gradle wrapper --gradle-version 9.4.1`。
2. `compileSdk = 37` + `android.suppressUnsupportedCompileSdk=37.2` 说明当前 AGP 尚未正式支持该编译版本，属于"压着抑制告警跑"。
3. `release` 用 debug 签名，直接发布会被商店拒；且 `isMinifyEnabled=false`。

## 6. 首次使用路径

1. 安装 → 启动 `MainActivity` → 默认落在**首页**（`selected=0`）。
2. 底部三 tab：首页 / 记账 / 报表（`LedgerBottomBar`，`ui/LedgerApp.kt:370`）。
3. 要开截屏记账：
   - 设置 → **功能管理** → 无障碍截图 → 打开系统无障碍服务（`ScreenshotAccessibilityService`，Android 11+ 免 Root）；
   - 或直接用磁贴 / 相册 / 拍照（MediaProjection 走 `ScreenshotRequestActivity`）；
   - 必须先配 **AI 模型与自动化**（Base URL、Key、Model），否则磁贴点击只会跳设置页（`tile/ScreenshotTileService.kt`）。
4. 通知确认：识别结果发高优先级通知，点"确认"→ `ConfirmEntryReceiver` → `LedgerRepository.add(source="截屏记账")`。
5. 历史数据迁移：老版本存在 `SharedPreferences("auto_ledger")` 的 JSON 账单，会被 `LedgerDbHelper.migrateFromPrefs` / `LedgerDatabase.migrateLegacy` 自动搬进 Room。
